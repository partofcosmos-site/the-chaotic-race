# The Ultimate Chaotic Merbl Race
This project is inspired from the project- <a href="https://github.com/karnxx/merbl"> https://github.com/karnxx/merbl <a/> <br>
I built this project during week 2 - cad week of <a href="https://halflife.hackclub.com">halflife<a/> <br>
THE  CHAOTIC RACE OF DEATH OR VICTORY. THE RACE TRACK IS SO BAD THAT IT LITERALLY PUSHES YOU TO THE END OF THE WORLD .😊 

Idea : 
The merbl will start moving from a slop top. just after it touches the track , it will move into the cyclonic track and then enter a straight path. There after moving in the same height, it will face the stairs path with inclination.Thereafter it will start moving through plinko track and move straight through a moving fan powered by battery. Then it will move again from a straight path and face a reduced height causing it to speed up and then move to a height and then face inclination and at the end drop into the "Avenger Tower".
